הגדרה ראשונית (למפתח/ת בלבד, פעם אחת). בוחרים שם משתמש וסיסמה לחשבון הניהול, ומדביקים GitHub Personal Access Token (מסוג Fine-grained) עם הרשאת Contents: Read and write, מוגבל רק לריפו moroshabat. אפשר ליצור טוקן כזה ב- github.com/settings/personal-access-tokens/new — תחת Repository access בחר "Only select repositories" ובחר moroshabat, ותחת Permissions בחר Contents: Read and write. הסיסמה מצפינה את הטוקן ולא נשמרת בשום מקום כטקסט גלוי; הגרסה המוצפנת נשמרת בריפו עצמו, כך שמכאן והלאה אפשר להתחבר מכל מחשב או טלפון רק עם שם משתמש וסיסמה — בלי טוקן ובלי GitHub בכלל. לכן כדאי לבחור סיסמה חזקה וייחודית.
