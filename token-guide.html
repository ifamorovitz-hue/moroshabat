חידוש טוקן הגישה

טוקן הגישה מאפשר לאתר לשמור שינויים בשם יפעת. כשהוא פג תוקף, הכניסה לניהול מפסיקה לעבוד, וזה המדריך ליצירת טוקן חדש והזנתו מחדש.

לא דורש ידע טכניפעם בשנהכ-3 דקות
מתי עושים את זה? פעם בשנה, או בכל פעם שמופיעה הודעת שגיאה בהתחברות לניהול. אין נזק אם עושים את זה מוקדם מדי, טוקן חדש פשוט מחליף את הישן.

חלק 1: יצירת טוקן חדש ב-GitHub

נכנסים לחשבון ה-GitHub של יפעת (בעלת הריפו) ויוצרים מפתח גישה חדש ששייך רק לאתר moroshabat.

  1. פותחים את דף היצירה

    לוחצים על הכפתור, ואם מבקשים להתחבר, מתחברים עם חשבון ה-GitHub.

    יצירת טוקן חדש

  2. נותנים שם לטוקן

    בשדה Token name כותבים שם שכולל את השנה כדי לזהות אותו בעתיד, למשל moroshabat-2027.

  3. בוחרים תוקף ארוך

    בשדה Expiration בוחרים את האפשרות הארוכה ביותר (בדרך כלל שנה), כדי שיישאר תקף כמה שיותר זמן.

  4. מגבילים לריפו של האתר בלבד

    בשדה Repository access בוחרים Only select repositories, ואז ברשימה בוחרים את moroshabat בלבד. כך הטוקן לא נותן גישה לשום דבר אחר בחשבון.

  5. נותנים הרשאת עריכה לקבצים

    ב-Repository permissions מחפשים את השורה Contents ובתפריט שלצידה בוחרים Read and write.

  6. יוצרים את הטוקן

    גוללים עד הסוף ולוחצים על הכפתור הירוק Generate token.

  7. מעתיקים אותו מיד

    הטוקן (מתחיל ב-github_pat_) מוצג פעם אחת בלבד. מעתיקים אותו לפני שסוגרים או עוברים לדף אחר.

    אם עזבת את הדף בלי להעתיק, מתחילים את חלק 1 מחדש. שום נזק לא נגרם.

חלק 2: עדכון הטוקן באתר

מכניסים את הטוקן החדש כדי שיחליף את הישן.

  1. גוללים לתחתית האתר

    בשורה התחתונה מופיע הקישור הקטן "הגדרות מפתחים". לוחצים עליו.

  2. ממלאים את הפרטים

    שם משתמש וסיסמה: אפשר להזין את אותם שם משתמש וסיסמה כמו תמיד (סיסמה של 8 תווים לפחות, עם אות גדולה באנגלית, אות קטנה באנגלית ומספר). בשדה GitHub Token מדביקים את הטוקן החדש שהועתק בחלק 1.

  3. שומרים

    לוחצים על "שמירה". הודעה ירוקה אומרת שהצליח והכניסה תקינה לשנה נוספת. הודעה אדומה אומרת שכדאי לוודא שהועתק הטוקן המלא, ולנסות שוב.

שאלות נפוצות

שכחתי להעתיק את הטוקן, מה עכשיו?

אין בעיה. חוזרים לחלק 1 ויוצרים טוקן חדש. הטוקן הישן שנוצר בטעות פשוט לא ישמש לשום דבר.

האם מישהו אחר יכול להשתמש בטוקן הזה?

הוא מוגבל אך ורק לאתר moroshabat (בזכות שלב 4), והוא נשמר מוצפן. גם מי שיראה אותו לא יכול לעשות איתו כלום בלי הסיסמה של הניהול.
